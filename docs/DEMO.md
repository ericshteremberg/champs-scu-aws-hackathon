## Pitch wording

“Causality prepares a dispute case from records a business already has. A merchant-controlled API shares only evidence linked to an approved case. The organizer gets sourced findings, unresolved gaps, and a response to review. AWS Lambda runs the investigation, Bedrock Nova reasons over the evidence, and DynamoDB and S3 preserve the case and its sources. We are validating the preparation time saved with ATMSPHR before expanding to rentals.”

For a sample run, say: “This run uses our labeled deterministic sample investigator. The same review workflow supports Bedrock investigations, and all persisted application data in this deployment is stored in AWS.”

## Questions to prepare for

**Where is AWS used?** Lambda owns the API and background jobs. DynamoDB stores workspace entities and version guards. S3 stores uploaded files and approved archives. Bedrock performs model inference and tool selection. Cloudflare hosts the frontend and authenticated bridge only.

**What is implemented?** A usable review interface, bounded investigation engine, persisted traces, scoped evidence client, citation checks, cancellation, stale-result protection, private files, and approved export/archive. Present each deployed feature only after its acceptance check succeeds.

**What makes it different?** The initial hypothesis is a practical integration for custom ticketing data, merchant-controlled case scope, and transparent review. Automated dispute products already exist; uniqueness and demand have not been established.

**Does it issue refunds or submit automatically?** No refund or customer-message action exists. The investigator writes a draft. The separately enabled Stripe path requires a current approved revision and explicit confirmation; it is not part of the standard demo.

**Are its conclusions guaranteed?** No. Citation validation confirms that a referenced record was retrieved. The organizer still checks whether it supports the claim.

**Can it inspect the whole database?** The model receives only section tools for one fixed case. The merchant endpoint must enforce the grant and filter rows and fields before responding. The endpoint contract is implemented on Causality's side; ATMSPHR's production endpoint still needs deployment and verification.

**What should the pilot prove?** A useful, accurate reviewed packet with less operator effort, acceptable integration cost, and willingness to pay. See [BUSINESS.md](BUSINESS.md).
